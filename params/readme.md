# ZEMI parameter files

This directory contains complete component configurations using ZEMI Params
0.3. The canonical documentation and example live in the bundled `zemi`
library:

- [ZEMI Params 0.3 specification](../zemi/docs/ZEMI_PARAMS_0.3.md)
- [Complete Params 0.3 TOML example](../zemi/examples/params/full_params_0.3.toml)
- [Dataset optimization and adapter contracts](../zemi/docs/DATASET_OPTIMIZATION.md)

Keep component-specific configurations in this directory. Keep specifications
and reusable full examples in the `zemi` library so all components reference a
single source of truth.
